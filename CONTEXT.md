# Контекст проекта

Рабочие заметки для продолжения в новом чате. Обновлено 29 августа 2026 года.

## Что это

Telegram-бот, который отвечает через Gemini. Помнит контекст диалога в пределах чата, пока запущен процесс.

Бот в Telegram: [@pa_gemini_chat_bot](https://t.me/pa_gemini_chat_bot), имя «Gemini Chat».
Репозиторий: [afapetr-ui/gemini-telegram-bot](https://github.com/afapetr-ui/gemini-telegram-bot), приватный.
Аккаунты: GitHub — `afapetr-ui`, Google — `afa.petr@gmail.com`.

## Что уже работает

Код готов и лежит в репозитории. Локально бот запускается командой `.venv/bin/python bot.py` и работает через long polling. Виртуальное окружение собрано на Python 3.13 из Miniconda: системный Python 3.9 не годится, под него не собирается `cryptography`, поэтому в `requirements.txt` стоит ограничение `cryptography<49`.

Ключ Gemini и токен бота лежат в `.env`, он не попадает в коммиты. Модель — `gemini-3.5-flash`, параметр `THINKING_BUDGET=-1` разрешает ей самой решать, сколько обдумывать ответ: это добавляет около секунды, зато ответы точнее.

## Что осталось сделать

Развернуть бота на Render, чтобы он работал без включённого Мака.

Дошли до входа в Render — там нужен вход через GitHub, а в браузере Cursor сессия GitHub не открыта. На этом остановились.

Дальнейшие шаги: войти в Render, создать сервис по `render.yaml` (Blueprint), вписать в переменные окружения `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY` — они помечены `sync: false`, поэтому Render запросит их вручную. После деплоя убедиться, что в логах есть строка `Application started`, и написать боту в Telegram.

Запасной вариант, если вход через GitHub не пойдёт: сделать репозиторий публичным (секретов в нём нет) и зарегистрироваться в Render через Google, а код подключить по прямой ссылке на репозиторий.

## Как устроен деплой

Бот сам определяет режим работы. Если Render передал `RENDER_EXTERNAL_URL` и `PORT`, бот поднимает веб-сервер на tornado, регистрирует адрес вебхука в Telegram и проверяет подпись апдейтов по `WEBHOOK_SECRET` (Render генерирует его сам). Если переменных нет, работает через опрос — это локальный режим.

Бесплатный сервис Render засыпает после 15 минут без входящих запросов, поэтому бот раз в 10 минут дёргает собственный адрес. Режим вебхуков проверен локально: сервер поднимается, порт слушает.

## Ограничения, о которых стоит помнить

Бесплатный тариф Gemini API даёт 5 запросов в минуту и 20 в сутки. Pro-модели на нём недоступны: квота равна нулю, нужен платёжный аккаунт Google Cloud. Подписка Google AI Pro на API не распространяется, она действует только внутри веб-интерфейса AI Studio. При этом в подписку входят бенефиты Google Developer Program — 10 долларов в месяц кредитами Google Cloud, их можно один раз активировать и потратить на API. К этому решили вернуться позже.

История диалога хранится в памяти процесса: после перезапуска бот забывает разговор. Отвечает он всем, кто напишет.

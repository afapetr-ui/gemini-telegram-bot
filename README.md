# gemini-telegram-bot

Telegram-бот, который отвечает на сообщения через Gemini. Помнит контекст диалога в пределах чата, пока процесс запущен.

## Что нужно

- Python 3.11+ (проект собран на 3.13)
- Токен бота от [@BotFather](https://t.me/BotFather)
- API-ключ Gemini из [Google AI Studio](https://aistudio.google.com/apikey)

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Впишите в `.env` токен бота и ключ Gemini.

## Запуск

```bash
.venv/bin/python bot.py
```

Локально бот работает на long polling: пока процесс запущен, он отвечает. Закрыли терминал — бот замолчал.

## Хостинг на Render

В репозитории лежит `render.yaml` — Render поднимет сервис по нему сам. Нужно только вписать в переменные окружения `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY`, остальное подставится.

Когда Render передаёт `RENDER_EXTERNAL_URL` и `PORT`, бот переключается с опроса на вебхуки: поднимает веб-сервер, регистрирует адрес в Telegram и проверяет подпись каждого апдейта по `WEBHOOK_SECRET`. Бесплатный сервис засыпает после 15 минут тишины, поэтому бот раз в 10 минут дёргает собственный адрес и не даёт себе уснуть.

## Команды

- `/start` — приветствие
- `/reset` — очистить контекст разговора и вложения

Можно прислать фото, PDF, Word, Excel, текст, CSV, голос или видео и в подписи написать, что сделать: разобрать, посчитать, найти в сети. Следующие сообщения без файла всё ещё видят последнее вложение, пока не нажать `/reset`.

## Настройки

Все параметры лежат в `.env`:

| Переменная | Что делает |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `GEMINI_API_KEY` | ключ из Google AI Studio |
| `GEMINI_MODEL` | модель, по умолчанию `gemini-3.5-flash` |
| `THINKING_BUDGET` | `-1` — модель сама решает, сколько думать; `0` — не думать вовсе |
| `SYSTEM_INSTRUCTION` | системный промпт: тон и правила ответа |
| `WEBHOOK_SECRET` | подпись вебхука, нужна только на хостинге |

## Ограничения

- Бесплатный тариф Gemini API даёт 5 запросов в минуту и 20 в сутки. Pro-модели на нём недоступны: их квота равна нулю, нужен платёжный аккаунт Google Cloud. Подписка Google AI Pro на API не распространяется, она работает только внутри веб-интерфейса AI Studio.
- История диалога хранится в памяти процесса: после перезапуска бот забывает разговор.
- Бот отвечает всем, кто ему напишет. Если нужен доступ только для себя, добавьте проверку `update.effective_user.id`.
